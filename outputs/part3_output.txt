10.12  RSIFlow vs Self-HPO: which adaptation fits a debugging agent?
==============================================================================
                RSIFlow (2610.21791)              Self-HPO (2610.22791)
 what adapts    workflow orchestration            harness AND policy, alternately
 who proposes   an evolving meta-agent            the policy itself (H-step)
 trigger        the current performance bottleneck failures of the current policy
 fits us when   many pipeline stages to route     one agent loop + tunable test/CI harness

Our agent is ONE loop (CI -> patch -> CI) with tunable harness knobs (how many tests,
how many patches per round, diagnostics on/off).  That is Self-HPO's shape, so we use it.
(RSIFlow's multi-stage router would need a multi-stage pipeline; lab 10.13 is skipped.)
